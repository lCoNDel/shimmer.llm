Sobre el Proyecto

CARTÓGRAFO Marino es una plataforma cartográfica profesional desarrollada como demo para Touron S.A, diseñada para fusionar datos marítimos en tiempo real con una base de datos geoespacial corporativa.

Resumen de Funcionalidades Técnicas

  • AIS y Tráfico Marítimo: Monitorización de buques en tiempo real mediante integración asíncrona de VesselFinder.
  • Regla Náutica Digital: Cálculo preciso de distancias en Millas Náuticas (nm) y rumbos entre coordenadas.
  • Alarma de Fondeo (Anchor Watch): Vigilancia GPS activa con radio de seguridad ajustable, alertas sonoras y notificaciones del sistema.
  • Reporte Meteorológico Marino: Consumo de datos en tiempo real (oleaje, viento y temperatura) a través de la API abierta de Open-Meteo y OpenSeaMap.
  • Entretenimiento en Navegación: Reproductor de radio global integrado con acceso a más de 90,000 emisoras en streaming.
  • Base de Datos y Renderizado: Motor de gestión de red de distribución con marcadores SVG dinámicos y filtrado reactivo.
  • Motor de Geocoding Global: Búsqueda de puertos y rías apoyada en Nominatim (OSM) y geolocalización nativa del usuario.
