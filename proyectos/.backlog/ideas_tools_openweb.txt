PENDIENTES DE IMPLEMENTAR
--------------------------

fetch_url
  - Descarga el contenido de una URL y lo devuelve al agente
  - Detectar Content-Type: si es HTML → extraer texto limpio (httpx + BeautifulSoup)
  - Si es PDF → parsear con pypdf (misma lógica que doc_reader.py)
  - Una sola tool que maneje ambos casos
  - Requirements: httpx, beautifulsoup4, pypdf

code_run
  - Ejecuta código Python en sandbox dentro del contenedor y devuelve el output al chat
  - El usuario ve código + resultado en la misma conversación (igual que intérprete ChatGPT)
  - Opciones: subprocess restringido o exec() con captura de stdout/stderr
  - OJO seguridad: solo activar en agentes con usuarios de confianza

erp_query
  - Consultas al ERP Libra (Oracle) desde el chat
  - Requiere definir qué datos son consultables y por quién
  - Pendiente de diseño — depende de la disponibilidad de API o conector Libra
