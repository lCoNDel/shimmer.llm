Qwen — Recomendaciones de System Prompt
Fuente: docs oficiales QwenLM (abril 2026)

## Estructura general
- No hay estructura de secciones rígida (a diferencia de Anthropic).
- Puede ser minimalista ("You are a helpful assistant") o muy detallado (lista de restricciones explícitas).
- El system prompt debe ser estable a lo largo de toda la conversación — el modelo no debe "escapar" del rol en turnos posteriores.
- Capacidades documentadas: role-playing, restricciones de comportamiento, transfer de estilo de lenguaje, configuración de tareas.

## Thinking mode (Qwen3)
- Activar/desactivar desde el PRIMER MENSAJE DEL USUARIO, no desde el system:
    /think    → activa razonamiento interno
    /no_think → desactiva razonamiento interno
- Parámetros recomendados con thinking habilitado:
    temperature=0.6, top_p=0.95, top_k=20, min_p=0
    NO usar greedy decoding (provoca degradación y repetición infinita).
- En conversaciones multi-turno: el historial debe incluir solo la RESPUESTA FINAL, no el bloque <think>.

## Tool use / agentes
- No hay estructura especial de system prompt para tool use.
- Qwen3 gestiona function calling a través del chat template (Jinja2), tanto en modo thinking como sin él.
