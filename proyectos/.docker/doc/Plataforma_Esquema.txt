#########################################################
# Proyecto: Shimmer LLM (Asistentes y Entornos)
#########################################################

Este documento define el estándar de puertos para todos los servicios dockerizados actuales y futuros del proyecto. El objetivo es mantener un orden lógico y coherente para evitar colisiones a medida que el sistema escale (más entornos de desarrollo, múltiples filebrowsers inyectables y más bots).

=========================================================
BLOQUE 3000: INTERFACES Y PRODUCCIÓN
=========================================================
Interfaces principales utilizadas en el día a día.
- 3000 : Open WebUI (Producción)
- 3001 : AnythingLLM (Producción)
- 3002 a 3099 : Reservado para futuras interfaces estables (LibreChat, Flowise, etc.)

=========================================================
BLOQUE 8000: HERRAMIENTAS DE GESTIÓN Y MONITOREO
=========================================================
Servicios de administración interna del sistema.
- 8000 : Filebrowser Global (Acceso raíz a todo el árbol)
- 8001 : Filebrowser Inyectable -> Open WebUI
- 8002 : Filebrowser Inyectable -> AnythingLLM
- 8003 a 8099 : Reservado para nuevas herramientas (Grafana, Portainer, etc.)

=========================================================
BLOQUE 4000: ENTORNOS DE DESARROLLO Y PRUEBAS
=========================================================
Clones inestables de producción para realizar experimentos.
- 4000 : Open WebUI (Entorno Dev)
- 4001 : AnythingLLM (Entorno Dev)
- 4002 a 4099 : Reservado para futuros contenedores en fase de experimentación.

=========================================================
BLOQUE 5000: APIs Y SERVICIOS BACKEND
=========================================================
Servicios conectables que no disponen de interfaz visual accesible.
- 5000 a 5099 : APIs nativas, webhooks, microservicios de enrutamiento o puentes de IA.

=========================================================
BOTS Y ASISTENTES
=========================================================
A menos que se implemente una arquitectura explícita de webhooks, en cuyo caso usarán el Bloque 5000, los bots de arquitectura Long Polling (Telegram, Discord, Whatsapp) se conectan externamente y no requieren exponer puertos en la máquina local.

- Asistente Náutico : [Sin puerto]
- Futuros Bots : [Sin puerto] 

=========================================================
BASES DE DATOS Y CACHÉ
=========================================================
Siempre se mantendrán en sus puertos estándar/oficiales para facilitar su rápida identificación técnica.
- 11434 : Ollama (Host)
- 5432 / 5433 : PostgreSQL
- 6379 : Redis
