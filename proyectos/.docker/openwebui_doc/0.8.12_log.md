## 📦 Cambios por Versión

### **v0.8.11** - Cambios Principales

#### ✨ Características Nuevas

- **🔀 Responses API Mejorada**
  - Streaming mejorado de respuestas
  - Re-invocaciones de tool calls sin duplicados

- **🧪 Sesiones Stateful (Experimental)**
  - Support para respuestas API con sesiones stateful
  - Backends compatibles pueden mantener estado sesión

- **📄 Paginación de Archivos**
  - `view_file` y `view_knowledge_file` soportan offset/max_chars
  - Mejor manejo de archivos grandes

- **🗺️ Búsqueda de Knowledge Confinada**
  - Respeta solo knowledge bases adjuntas al modelo
  - Más seguro y eficiente

- **🛠️ Contexto en Embeds HTML**
  - Tools pueden retornar contexto customizado junto con embeds
  - Mejor integración de contenido embebido

- **🔒 Header de Rol OIDC Confiable**
  - `WEBUI_AUTH_TRUSTED_ROLE_HEADER` para roles vía proxy IdP
  - Seguridad mejorada en autenticación

- **🔑 Parámetros de Autorización OIDC**
  - `OAUTH_AUTHORIZE_PARAMS` para pre-selección de IdP
  - `GOOGLE_OAUTH_AUTHORIZE_PARAMS` para refresh tokens
  - Multi-dispositivo soportado

- **🏮 Manejo Binario en Tools**
  - Soporte para retornar imágenes y datos binarios
  - Mejor integración multimedia

- **⚡ Performance +25%**
  - Actualización de Svelte
  - Optimizaciones de renderizado frontend
  - Carga más rápida de interfaz

- **📁 Chat Folder Emoji Reset**
  - Botón para resetear emojis a defaults
  - Gestión mejorada de carpetas

- **🔩 Configuración de Tool Server Timeout**
  - `AIOHTTP_CLIENT_TIMEOUT_TOOL_SERVER`
  - Control fino de timeouts

- **🏥 Endpoint `/ready` para Kubernetes**
  - Readiness probe mejorada
  - Mejor compatibilidad con orquestación

- **📌 Previsualizaciones de Archivos Knowledge**
  - Abrir en nueva pestaña
  - UX mejorada

- **✏️ Edición de Markdown**
  - Soporte para editar archivos Markdown
  - Editor integrado

- **🖥️ Formatting Python Offline**
  - Black formatter bundled en Docker
  - Funcionamiento sin conexión

## 📋 Nuevas Variables de Entorno (v0.8.11+)

| Variable | Propósito | Defecto |
|----------|-----------|---------|
| `WEBUI_AUTH_TRUSTED_ROLE_HEADER` | Header de rol confiable desde proxy IdP | (none) |
| `OAUTH_AUTHORIZE_PARAMS` | Parámetros extra en redirect OIDC | (none) |
| `GOOGLE_OAUTH_AUTHORIZE_PARAMS` | Parámetros para Google OAuth refresh tokens | (none) |
| `AIOHTTP_CLIENT_TIMEOUT_TOOL_SERVER` | Timeout específico para tool servers | (default) |
| `ENABLE_PIP_INSTALL_FRONTMATTER_REQUIREMENTS` | Auto pip install toggle | true |
| `OAUTH_GROUP_DEFAULT_SHARE` | Default share setting para OAuth groups | (admin controlled) |
| `ENABLE_ADMIN_ANALYTICS` | Habilitar/deshabilitar analytics | true |
| `RAG_EMBEDDING_CONCURRENT_REQUESTS` | Max concurrent embedding requests | (configurable) |
